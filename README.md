# RAG Medical Agent

A Retrieval-Augmented Generation (RAG) system for querying medical documents and PDFs. This project consists of a FastAPI backend server and a Streamlit client dashboard.

## Project Structure

- `client/`: Streamlit web interface and components.
- `server/`: FastAPI server with LangChain, Pinecone, and LLM integrations.
- `uploaded_docs/`: Temporary storage for uploaded PDF files (ignored in Git).
